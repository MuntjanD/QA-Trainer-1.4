# BuggyThreads Co. - QA Trainee Sandbox & Report Evaluator (v1.6)

A deliberately buggy e-commerce storefront used as a QA practice sandbox. The app is designed to help trainees explore UI and API bugs, validate forms, analyze security issues, and practice test automation.

## 🚀 What's New in Version 1.6

* **✨ New Features**
    * Added an expanded Playwright automated testing module to handle a larger volume of test scenarios[cite: 1].
    * Introduced an expanded API Test panel with additional endpoints for deeper verification[cite: 1].
    * Integrated new instruments into the QA Control Center for more precise real-time bug tracking[cite: 1].

* **🐛 Bug Fixes**
    * Fixed shopping cart and checkout logic flaws that were present in version 1.4[cite: 1].
    * Resolved text overflow UI defects and currency conversion bugs[cite: 1].
    * Patched security vulnerabilities such as SQL Injection in the authentication form[cite: 1].

* **⚡ Improvements**
    * Optimized the built-in Mock API by reducing latency for a faster experience under the `file://` protocol[cite: 1].
    * Enhanced the SQL database structure for more efficient searching and filtering inside the SQL Playground[cite: 1].

## 🛠️ Getting Started

1. Download or clone the repository.
2. Open `QA_Trainee_Vers_1_6.html` directly in your browser or run it through a local server.
3. Use the integrated **QA Control Center** to track bugs, test APIs, and evaluate bug reports.
